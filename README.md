# art-portfolio

Portfolio site for Milan Stevens (music, art, sculpture, makeup).

- Open `index.html` in a browser; no build step.
- Theme overrides live in `assets/css/cosmic.css`.
- Add Music or Makeup photos to `images/music/` or `images/makeup/` and follow the commented example in each section of `index.html`.

Adapted from [Dimension by HTML5 UP](https://html5up.net/dimension) (CC BY 3.0).
